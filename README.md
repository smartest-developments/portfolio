# Simone Salvo — AI Product & Operations

The public portfolio source for a curated selection of private AI product and operations work.

## Daily curation

`scripts/portfolio_audit.py` reviews the private repository inventory available to the authenticated GitHub CLI and writes a local editorial report in `reports/`. It never copies project source code, credentials or private data into this repository.

The final inclusion decision follows [portfolio-policy.md](portfolio-policy.md). New public-facing case studies are added deliberately to `data/projects.js`, then GitHub Pages publishes the update from `main`.
